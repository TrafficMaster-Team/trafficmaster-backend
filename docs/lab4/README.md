# Лабораторная работа № 4 — API и безопасность

Объект: TrafficMaster, backend FastAPI. У проекта нет отдельной клиентской части. Вёрстка, мобильные размеры, масштаб страницы, favicon, hover, переход по логотипу и матрица совместимости трёх браузеров **неприменимы**. Эти проверки не выполнялись и не выдаются за выполненные.

Пункт 4 выполнен на существующем Swagger UI: это интерфейс вызова API, а не отдельный frontend. Playwright работает в одном Chromium; мобильная эмуляция и кроссбраузерные испытания исключены из объёма по отсутствию клиента.

## Воспроизведение

Нужны Python >=3.12, Node.js/npm и доступный Docker daemon. Команды из корня проекта:

```bash
uv sync --locked --group dev --group docs
npm ci --prefix postman
.venv/bin/playwright install chromium
.venv/bin/python scripts/run_lab4.py
```

При отсутствии системных библиотек Chromium используйте официальный `playwright install --with-deps chromium` в подходящем окружении. Запуск не требует Firefox/WebKit, установки мобильных устройств или запуска отдельного frontend.

Runner создаёт временные PostgreSQL 16 и Redis 7, применяет и проверяет миграции, запускает отдельный Uvicorn на свободном localhost-порту. Синтетический superadmin для позитивных административных операций создаётся только в этой временной БД: регистрация по API и повышение роли подготовительным SQL. Это подготовка стенда, не продуктовая возможность регистрации superadmin. После прогона сервер и контейнеры закрываются.

`--only api` запускает только Newman и проверки безопасных ошибок; `--only ui` — только Swagger UI и проверку скриншота. Полный прогон использует оба набора. **Текущий runner возвращает код 1**, потому что воспроизведённые дефекты действительно оставляют тесты неуспешными. Их нельзя скрывать `--suppress-exit-code` или менять ожидания на небезопасное поведение.

Локальный HTML-отчёт Postman можно открыть напрямую: `docs/lab4/evidence/newman.html`. Для сайта документации: `.venv/bin/mkdocs build --strict`.
